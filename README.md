# F.CSA313 – Лабораторийн ажил №8

## Mock объектууд — Mockito-гоор хамаарлыг орлуулж тестлэх

### 1. Зорилго
Mockito ашиглан Java програмын гаднын хамаарлуудыг Mock объектоор орлуулж, JUnit 5 болон Mockito-оор нэгж тест хийх.

### 2. Ашигласан технологи
- Java 17
- Apache Maven 3.9.6
- JUnit Jupiter 5.10.2
- Mockito 5.14.2
- Maven Surefire Plugin 3.2.5

### 3. Тестийн тохиолдлууд
- A1: Идэвхтэй оюутны бүртгэл амжилттай болох
- A2: Оюутан олдохгүй үед алдаа буцаах
- A3: Идэвхгүй оюутны бүртгэлийг хориглох
- A4: Урьдчилсан нөхцөл хангаагүй үед бүртгэхгүй байх
- A5: Имэйл илгээхэд алдаа гарсан ч бүртгэл хадгалагдах
- A6: Null оролтыг шалгах
- A7: Имэйлийн агуулгыг шалгах
- A8: Параметртэй тестээр олон алдааны хувилбар шалгах

### 4. Ашигласан Mockito боломжууд
- @Mock
- @InjectMocks
- when().thenReturn()
- verify()
- never()
- verifyNoInteractions()
- doThrow()
- ArgumentCaptor
- @ParameterizedTest
- @CsvSource

### 5. Энгийн тестийн үр дүн
mvn clean test:
- Tests run: 10
- Failures: 0
- Errors: 0
- Skipped: 0
- BUILD SUCCESS

### 6. Mutation Testing
- Mutant 1: Идэвхтэй эсэх шалгалтыг өөрчилсөн. A3 болон A8 тестүүд алдааг илрүүлсэн.
- Mutant 2: Бүртгэл хадгалах үйлдлийг хассан. Тестүүд алдааг илрүүлсэн.
- Mutant 3: Null шалгалтын нэг нөхцөлийг хассан. A6 тест алдааг илрүүлсэн.

Өөрчлөлт бүрийн дараа анхны кодыг сэргээж, эцэст нь бүх тестийг дахин ажиллуулсан.

### 7. Дүгнэлт
Энэ лабораторийн ажлаар Mockito ашиглан хамаарлуудыг Mock объектоор орлуулж, JUnit 5-ийн тусламжтайгаар нэгж тест хийж сурсан. Mutation Testing хийснээр тестүүд програмын логик алдааг илрүүлж байгааг шалгасан. Эцсийн үр дүнд 10 тест бүгд амжилттай болсон.
